# Anurag Dubey — Portfolio

Personal portfolio of Anurag Dubey, Python developer and founder of [Collabro](https://collabro.co.in).

**Live:** https://portfolio-opal-six-fyvh3d4gw2.vercel.app

## Stack
- React 19 + Vite
- Framer Motion, GSAP, Lenis (animation and smooth scroll)
- Three.js via React Three Fiber / Drei (3D)
- EmailJS + Vercel serverless function (`/api`) for the contact form
- Deployed on Vercel

## Run locally
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build && npm run preview
```
